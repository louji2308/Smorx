# smorx-verification

Independent verification modules for the Software Evolution Intelligence
System: static analysis, differential execution, historical ghost replay,
metamorphic checks, adversarial scenarios, and mutation testing. Per
`Architecture Diagram.md` and `Requirements & Contract.md`, these modules will
emit normalized per-claim evidence fused independently of the coding decision,
preserving the trust boundary between candidate changes and certification.

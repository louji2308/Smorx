# smorx-ui

Browser-facing client for the Software Evolution Intelligence System: the
eight journey tabs (Discover, Govern, Define, Analyze, Develop, Verify,
Decide, Certify) with contextual drawers and inspectors. Per `Architecture
Diagram.md` and `Final Demo Idea(2).md`, this package will implement a thin
client that reflects real backend state (workflow, trust, execution, evidence,
and certification state) rather than a separate intelligence layer. Rendering
is projected on the Next.js app in `apps/web`.
